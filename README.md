# My_Snippets
An attempt to create a mechanism for version control of the snippets I created when using the extension for… vscode https://github.com/tahabasri/snippets
Этот механизм реализуется в скрипте push_changes.sh, который может быть помещён в любой проект в корень проекта и позволяет автоматизировать обновление пользовательских сниппетов, которые находятся в системе контроля версий.
