# My_Snippets
An attempt to create a mechanism for version control of the snippets I created when using the extension for… vscode https://github.com/tahabasri/snippets <img alt="logo" src="https://github.com/tahabasri/snippets/blob/main/images/logo/logo.png" width="300" height="200">


This mechanism is implemented in the push_changes.sh script, which can be placed in any project at the project root and allows you to automate the updating of user snippets that are stored in the version control system.
